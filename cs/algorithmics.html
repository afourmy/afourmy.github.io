Reverse an array in place

Inverser un tableau sur place

Reverse the order of an array's elements in place, without allocating a new array. Two pointers start at the ends and swap elements, moving towards the middle.

Inverser l'ordre des éléments d'un tableau sur place, sans allouer un nouveau tableau. Deux pointeurs partent des extrémités et échangent les éléments en se rejoignant au centre. 

def reverse_in_place(array):
    left, right = 0, len(array) - 1
    while left < right:
        array[left], array[right] = array[right], array[left]
        left += 1
        right -= 1

Two Sum

Problème des deux sommes

Given an array of integers and a target integer, return the indices of the two numbers that add up to the target.

Étant donné un tableau d'entiers et un entier cible, renvoyer les indices des deux nombres dont la somme vaut la cible. 

def two_sum(array, target):
    seen = {}
    for index, value in enumerate(array):
        remaining = target - value
        if remaining in seen:
            return [index, seen[remaining]]
        seen[value] = index

Binary Search

Recherche dichotomique

Given an array of integers sorted in ascending order and an integer target, return the index of the target or -1 if it does not exist.

Étant donné un tableau d'entiers trié dans l'ordre croissant et un entier cible, renvoyer l'indice de la cible ou -1 si elle est absente.

  • When computing the middle index, we generally use left + (right - left) // 2 instead of (left + right) // 2 to avoid integer overflow problems.
  • It is best not to use a strict inequality because:
    • we exit the loop before the case left == right, so we need to check whether the middle index is the target after the loop.
    • we have left = middle + 1 and right = middle.
  • It is better to use <= instead, where left = middle + 1 and right = middle - 1.
  • Pour calculer l'indice du milieu, on utilise généralement left + (right - left) // 2 plutôt que (left + right) // 2 afin d'éviter les problèmes de dépassement entier.
  • Il vaut mieux ne pas utiliser une inégalité stricte car :
    • on sort de la boucle avant le cas left == right, il faut donc vérifier après la boucle si l'indice du milieu est la cible.
    • on a left = middle + 1 et right = middle.
  • Il est préférable d'utiliser <=, avec left = middle + 1 et right = middle - 1.
def search(array, target):
    left, right = 0, len(array) - 1
    while left <= right:
        middle = left + (right - left) // 2
        if array[middle] < target:
            left = middle + 1
        elif array[middle] > target:
            right = middle - 1
        else:
            return middle
    return -1

Dynamic Programming

Programmation dynamique

This section covers both bottom-up dynamic programming and top-down memoized recursion. The two are dual formulations of the same idea: a problem is decomposed into overlapping subproblems whose solutions are reused rather than recomputed. Bottom-up DP fills a table iteratively from the base cases up, while memoized recursion expresses the same recurrence directly and caches results as they are computed.

Cette section couvre à la fois la programmation dynamique ascendante et la récursion mémoïsée descendante. Ce sont deux formulations duales d'une même idée : un problème est décomposé en sous-problèmes qui se chevauchent et dont les solutions sont réutilisées plutôt que recalculées. La programmation dynamique ascendante remplit un tableau de manière itérative à partir des cas de base, tandis que la récursion mémoïsée exprime directement la même récurrence et met en cache les résultats à mesure qu'ils sont calculés.

Count paths in a grid

Compter les chemins dans une grille

Count all possible paths from the bottom-left to the top-right of an n × n grid, moving only right or up.

Compter tous les chemins possibles du coin inférieur gauche au coin supérieur droit d'une grille n × n, en se déplaçant uniquement vers la droite ou vers le haut.

Bottom-up dynamic programming:

Programmation dynamique ascendante :

def count_paths(n):
    dp = [[0 if i and j else 1 for i in range(n)] for j in range(n)]
    for i in range(1, n):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
    return dp[n - 1][n - 1]

Top-down recursion with memoization:

Récursion descendante avec mémoïsation :

from functools import cache

def count_paths(n):
    @cache
    def rec(i, j):
        return 1 if not i or not j else rec(i - 1, j) + rec(i, j - 1)

    return rec(n - 1, n - 1)

Closed-form combinatorial solution: any such path consists of n - 1 right moves and n - 1 up moves, so the count is the number of ways to choose which of the 2n - 2 steps are right moves, i.e. the binomial coefficient C(2n - 2, n - 1).

Solution combinatoire en forme close : un tel chemin est constitué de n - 1 déplacements vers la droite et n - 1 vers le haut, donc le nombre de chemins est le nombre de façons de choisir lesquels des 2n - 2 pas sont des déplacements vers la droite, soit le coefficient binomial C(2n - 2, n - 1).

from math import comb

def count_paths(n):
    return comb(2 * n - 2, n - 1)

Depth-First Search

Parcours en profondeur

Traverse a graph by exploring each branch as deeply as possible before backtracking. Starting from a source node, use a stack to visit neighbors before siblings; return the set of all reachable nodes.

Parcourir un graphe en explorant chaque branche aussi profondément que possible avant de revenir en arrière. À partir d'un nœud source, utiliser une pile pour visiter les voisins avant les frères ; renvoyer l'ensemble des nœuds accessibles. 

def dfs(graph, start):
    visited, stack = set(), [start]
    while stack:
        node = stack.pop()
        if node in visited:
            continue
        visited.add(node)
        stack.extend(graph[node])
    return visited

Breadth-First Search

Parcours en largeur

Traverse a graph layer by layer, visiting all neighbors of a node before moving on to their neighbors. Using a queue ensures that nodes are explored in order of distance from the start; return the set of all reachable nodes.

Parcourir un graphe couche par couche, en visitant tous les voisins d'un nœud avant de passer aux voisins suivants. L'utilisation d'une file garantit que les nœuds sont explorés par ordre de distance au nœud de départ ; renvoyer l'ensemble des nœuds accessibles. 

from collections import deque

def bfs(graph, start):
    visited, queue = set(), deque([start])
    while queue:
        node = queue.popleft()
        if node in visited:
            continue
        visited.add(node)
        queue.extend(graph[node])
    return visited

Dijkstra's Algorithm

Algorithme de Dijkstra

Compute the shortest distance from a source node to every other node in a graph with non-negative edge weights. A min-heap is used to repeatedly extract the closest unvisited node and relax the distances of its neighbors; return a dictionary mapping each reachable node to its shortest distance from the start.

Calculer la plus courte distance d'un nœud source à tous les autres nœuds d'un graphe à poids positifs. Un tas binaire est utilisé pour extraire à chaque étape le nœud non visité le plus proche et relâcher les distances de ses voisins ; renvoyer un dictionnaire associant chaque nœud accessible à sa plus courte distance au nœud de départ. 

from heapq import heappop, heappush

def dijkstra(graph, start):
    stack, result = [(0, start)], {}
    while stack:
        dist, node = heappop(stack)
        if node in result:
            continue
        result[node] = dist
        for neighbor, weight in graph[node].items():
            heappush(stack, (dist + weight, neighbor))
    return result

Fibonacci

Fibonacci

The Fibonacci sequence is defined by F(0) = 0, F(1) = 1, and F(n) = F(n - 1) + F(n - 2). Return the n-th term of the sequence.

La suite de Fibonacci est définie par F(0) = 0, F(1) = 1, et F(n) = F(n - 1) + F(n - 2). Renvoyer le n-ième terme de la suite.

Iterative version: only the two previous terms need to be kept in memory, giving constant space and linear time complexity.

Version itérative : seuls les deux termes précédents doivent être conservés en mémoire, ce qui donne une complexité en espace constant et en temps linéaire.

def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

Recursive version with memoization: a naive recursive implementation runs in exponential time because the same subproblems are recomputed; caching each result brings the complexity back down to linear time.

Version récursive avec mémoïsation : une implémentation récursive naïve est exponentielle car les mêmes sous-problèmes sont recalculés ; mettre en cache chaque résultat ramène la complexité à un temps linéaire.

from functools import cache

@cache
def fibonacci(n):
    return n if n < 2 else fibonacci(n - 1) + fibonacci(n - 2)

Length of a Collatz sequence

Longueur d'une suite de Collatz

The Collatz function is defined as f(n) = 3n + 1 if n is odd, and n // 2 otherwise. Starting from n, the function is iterated until the sequence reaches 1; return the number of steps required.

La fonction de Collatz est définie par f(n) = 3n + 1 si n est impair, et n // 2 sinon. À partir de n, la fonction est itérée jusqu'à ce que la suite atteigne 1 ; renvoyer le nombre d'étapes nécessaires. 

def collatz(n):
    return 3 * n + 1 if n % 2 else n // 2

def collatz_sequence_length(n):
    count = 0
    while n > 1:
        n = collatz(n)
        count += 1
    return count

Hamming weight

Poids de Hamming

The Hamming weight of an integer is the number of 1s in its binary representation.

Le poids de Hamming d'un entier est le nombre de 1 dans sa représentation binaire.

Using the built-in bin:

Avec la fonction native bin :

def hamming_weight(n):

Using the bitwise right-shift operator:

Avec l'opérateur de décalage binaire à droite :

def hamming_weight(n):
    weight = 0
    while n > 0:
        weight += n & 1
        n >>= 1
    return weight
