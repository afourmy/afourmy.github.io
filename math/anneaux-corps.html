Rings and Fields

Anneaux et corps

Definition. A ring is a set $A$ equipped with two internal operations $+$ and $\times$ such that $(A,+)$ is an abelian group (with neutral element denoted $0_A$), $\times$ is associative with neutral element $1_A$, and $\times$ distributes over $+$: $\forall a,b,c \in A,\ a(b+c)=ab+ac$ and $(a+b)c=ac+bc$. The ring is commutative if $\times$ is commutative.

Définition. Un anneau est un ensemble $A$ muni de deux lois internes $+$ et $\times$ tels que $(A,+)$ est un groupe abélien (d'élément neutre noté $0_A$), $\times$ est associative et possède un élément neutre $1_A$, et $\times$ est distributive par rapport à $+$ : $\forall a,b,c \in A,\ a(b+c)=ab+ac$ et $(a+b)c=ac+bc$. L'anneau est commutatif si $\times$ est commutative.

Proposition (Calculation rules). Let $A$ be a ring. For all $a,b \in A$: $0_A \cdot a = a \cdot 0_A = 0_A$, $(-a) \cdot b = a \cdot (-b) = -(a \cdot b)$, and $(-a)(-b) = ab$.

Proposition (Règles de calcul). Soit $A$ un anneau. Pour tous $a,b \in A$ : $0_A \cdot a = a \cdot 0_A = 0_A$, $(-a) \cdot b = a \cdot (-b) = -(a \cdot b)$, et $(-a)(-b) = ab$.

Proof.

$0_A \cdot a = (0_A+0_A) \cdot a = 0_A \cdot a + 0_A \cdot a$, so $0_A \cdot a = 0_A$ by cancellation. Then $(-a)b + ab = (-a+a)b = 0_A$, so $(-a)b = -(ab)$. Finally $(-a)(-b) + (-a)b = (-a) \cdot 0 = 0$, so $(-a)(-b) = ab$.

Démonstration.

$0_A \cdot a = (0_A+0_A) \cdot a = 0_A \cdot a + 0_A \cdot a$, d'où $0_A \cdot a = 0_A$ par simplification. Ensuite $(-a)b + ab = (-a+a)b = 0_A$, donc $(-a)b = -(ab)$. Enfin $(-a)(-b) + (-a)b = (-a) \cdot 0 = 0$, donc $(-a)(-b) = ab$.

Remark. If $1_A = 0_A$, then $A = \{0_A\}$ (for all $a \in A$, $a = a \cdot 1_A = a \cdot 0_A = 0_A$).

Remarque. Si $1_A = 0_A$, alors $A = \{0_A\}$ (pour tout $a \in A$, $a = a \cdot 1_A = a \cdot 0_A = 0_A$).

Definition. An element $a$ of a ring $A$ is invertible if there exists $b \in A$ such that $ab = ba = 1_A$. The set of invertible elements of $A$, denoted $A^\times$, forms a group under multiplication, called the group of units of $A$.

Définition. Un élément $a$ d'un anneau $A$ est inversible s'il existe $b \in A$ tel que $ab = ba = 1_A$. L'ensemble des éléments inversibles de $A$, noté $A^\times$, forme un groupe pour la multiplication, appelé groupe des inversibles de $A$.

Proof.

If $a$ and $b$ are invertible, then $(ab)(b^{-1}a^{-1}) = a(bb^{-1})a^{-1} = 1$ and $(b^{-1}a^{-1})(ab) = b^{-1}(a^{-1}a)b = 1$, so $ab$ is invertible with inverse $b^{-1}a^{-1}$. The element $1_A$ is invertible (its own inverse). If $a$ is invertible, so is $a^{-1}$ (with inverse $a$). Associativity is inherited from $A$.

Démonstration.

Si $a$ et $b$ sont inversibles, alors $(ab)(b^{-1}a^{-1}) = a(bb^{-1})a^{-1} = 1$ et $(b^{-1}a^{-1})(ab) = b^{-1}(a^{-1}a)b = 1$, donc $ab$ est inversible d'inverse $b^{-1}a^{-1}$. L'élément $1_A$ est inversible (d'inverse lui-même). Si $a$ est inversible, $a^{-1}$ l'est aussi (d'inverse $a$). L'associativité est héritée de $A$.

Definition. An element $a \neq 0_A$ is a zero divisor if there exists $b \neq 0_A$ such that $ab = 0_A$ or $ba = 0_A$. A commutative ring is an integral domain if it has no zero divisors, i.e.: $\forall a,b \in A,\ ab = 0_A \implies a = 0_A \text{ or } b = 0_A$.

Définition. Un élément $a \neq 0_A$ est un diviseur de zéro s'il existe $b \neq 0_A$ tel que $ab = 0_A$ ou $ba = 0_A$. Un anneau commutatif est intègre s'il n'a pas de diviseur de zéro, c'est-à-dire : $\forall a,b \in A,\ ab = 0_A \implies a = 0_A \text{ ou } b = 0_A$.

Proposition. In an integral domain, cancellation holds: if $a \neq 0$ and $ab = ac$, then $b = c$.

Proposition. Dans un anneau intègre, on peut simplifier : si $a \neq 0$ et $ab = ac$, alors $b = c$.

Proof.

$ab = ac \implies a(b-c) = 0$. Since $a \neq 0$ and the ring is an integral domain, $b - c = 0$, so $b = c$.

Démonstration.

$ab = ac \implies a(b-c) = 0$. Comme $a \neq 0$ et l'anneau est intègre, $b - c = 0$, donc $b = c$.

Proposition. An invertible element is not a zero divisor.

Proposition. Un élément inversible n'est pas diviseur de zéro.

Proof.

Let $a$ be invertible and $ab = 0$. Multiplying by $a^{-1}$, we get $b = 0$.

Démonstration.

Soit $a$ inversible et $ab = 0$. En multipliant par $a^{-1}$, $b = 0$.

Definition. A field is a commutative ring in which every nonzero element is invertible, i.e. $K^\times = K \setminus \{0_K\}$.

Définition. Un corps est un anneau commutatif dont tout élément non nul est inversible, c'est-à-dire $K^\times = K \setminus \{0_K\}$.

Remark. Every field is an integral domain (every nonzero element of a field is invertible, hence not a zero divisor).

Remarque. Tout corps est intègre (tout élément non nul d'un corps est inversible, donc n'est pas diviseur de zéro).

Proposition. Every finite commutative integral domain is a field.

Proposition. Tout anneau commutatif fini intègre est un corps.

Proof.

Let $a \neq 0$ in a finite integral domain $A$. The map $\varphi : A \to A$ defined by $\varphi(x) = ax$ is injective: if $ax = ay$ then $a(x-y) = 0$, so $x = y$ by the integral domain property. Since $A$ is finite, $\varphi$ is also surjective. So there exists $b \in A$ with $ab = 1$, showing $a$ is invertible.

Démonstration.

Soit $a \neq 0$ dans $A$ fini et intègre. L'application $\varphi : A \to A$ définie par $\varphi(x) = ax$ est injective : si $ax = ay$, alors $a(x-y) = 0$, d'où $x = y$ par intégrité. Comme $A$ est fini, $\varphi$ est aussi surjective. Il existe donc $b \in A$ tel que $ab = 1$, ce qui montre que $a$ est inversible.

Definition. A subset $B$ of a ring $A$ is a subring of $A$ if $B$ is closed under $+$, $\times$, and negation, and if $1_A \in B$.

Définition. Un sous-ensemble $B$ d'un anneau $A$ est un sous-anneau de $A$ si $B$ est stable par $+$, $\times$ et opposé, et si $1_A \in B$.

Proposition (Subring criterion). $B \subset A$ is a subring if and only if $1_A \in B$, $\forall a,b \in B,\ a - b \in B$, and $\forall a,b \in B,\ ab \in B$.

Proposition (Critère de sous-anneau). $B \subset A$ est un sous-anneau si et seulement si $1_A \in B$, $\forall a,b \in B,\ a - b \in B$, et $\forall a,b \in B,\ ab \in B$.

Proof.

The condition is necessary. Conversely, (1) ensures $B \neq \varnothing$. By (2), $B$ is a subgroup of $(A,+)$ (subgroup criterion). By (3), $B$ is closed under multiplication. Associativity and distributivity are inherited from $A$, and (1) provides the neutral element.

Démonstration.

La condition est nécessaire. Réciproquement, (1) assure $B \neq \varnothing$. Par (2), $B$ est un sous-groupe de $(A,+)$ (critère de sous-groupe). Par (3), $B$ est stable par multiplication. L'associativité et la distributivité sont héritées de $A$, et (1) fournit l'élément neutre.

Proposition. The intersection of subrings is a subring.

Proposition. L'intersection de sous-anneaux est un sous-anneau.

Proof.

The element $1_A$ belongs to all subrings. Closure under difference and product is preserved by intersection.

Démonstration.

L'élément $1_A$ appartient à tous les sous-anneaux. La stabilité par différence et par produit est conservée par intersection.

Definition. Let $\varphi : A \to B$ be a map between two rings. We say $\varphi$ is a ring homomorphism if $\varphi(a + b) = \varphi(a) + \varphi(b)$, $\varphi(ab) = \varphi(a)\varphi(b)$ for all $a,b \in A$, and $\varphi(1_A) = 1_B$.

Définition. Soit $\varphi : A \to B$ une application entre deux anneaux. On dit que $\varphi$ est un morphisme d'anneaux si $\varphi(a + b) = \varphi(a) + \varphi(b)$, $\varphi(ab) = \varphi(a)\varphi(b)$ pour tous $a,b \in A$, et $\varphi(1_A) = 1_B$.

Proposition. If $\varphi : A \to B$ is a ring homomorphism, then $\varphi(0_A) = 0_B$, $\varphi(-a) = -\varphi(a)$, and $\varphi$ is injective if and only if $\ker\varphi = \{0\}$ (since $\varphi$ is in particular a homomorphism of additive groups).

Proposition. Si $\varphi : A \to B$ est un morphisme d'anneaux, alors $\varphi(0_A) = 0_B$, $\varphi(-a) = -\varphi(a)$, et $\varphi$ est injectif si et seulement si $\ker\varphi = \{0\}$ (car $\varphi$ est en particulier un morphisme de groupes additifs).

Proposition. The image of a ring homomorphism is a subring. The kernel $\ker\varphi = \{a \in A \mid \varphi(a) = 0_B\}$ is a subgroup of $(A,+)$ closed under multiplication by any element of $A$.

Proposition. L'image d'un morphisme d'anneaux est un sous-anneau. Le noyau $\ker\varphi = \{a \in A \mid \varphi(a) = 0_B\}$ est un sous-groupe de $(A,+)$ stable par multiplication par tout élément de $A$.

Proof.

$\mathrm{Im}\,\varphi$ contains $1_B = \varphi(1_A)$, is closed under difference and product. For the kernel: if $x \in \ker\varphi$ and $a \in A$, then $\varphi(ax) = \varphi(a)\varphi(x) = \varphi(a) \cdot 0 = 0$, so $ax \in \ker\varphi$.

Démonstration.

$\mathrm{Im}\,\varphi$ contient $1_B = \varphi(1_A)$, est stable par différence et par produit. Pour le noyau : si $x \in \ker\varphi$ et $a \in A$, alors $\varphi(ax) = \varphi(a)\varphi(x) = \varphi(a) \cdot 0 = 0$, donc $ax \in \ker\varphi$.

Proposition. Every field homomorphism (ring homomorphism between two fields) is injective.

Proposition. Tout morphisme de corps (morphisme d'anneaux entre deux corps) est injectif.

Proof.

Let $\varphi : K \to L$ be a field homomorphism and $x \in \ker\varphi$. If $x \neq 0$, then $x$ is invertible in $K$, so $1_L = \varphi(1_K) = \varphi(x)\varphi(x^{-1}) = 0 \cdot \varphi(x^{-1}) = 0_L$. But $1_L = 0_L$ would imply $L = \{0_L\}$, contradicting the fact that $L$ is a field (since $L^\times = L \setminus \{0_L\}$ must be a group, hence nonempty). So $x = 0$ and $\ker\varphi = \{0\}$.

Démonstration.

Soit $\varphi : K \to L$ un morphisme de corps et $x \in \ker\varphi$. Si $x \neq 0$, alors $x$ est inversible dans $K$, donc $1_L = \varphi(1_K) = \varphi(x)\varphi(x^{-1}) = 0 \cdot \varphi(x^{-1}) = 0_L$. Or $1_L = 0_L$ impliquerait $L = \{0_L\}$, ce qui contredit le fait que $L$ est un corps (car $L^\times = L \setminus \{0_L\}$ doit être un groupe, donc non vide). Donc $x = 0$ et $\ker\varphi = \{0\}$.

Definition. An ideal of a commutative ring $A$ is a subgroup $(I,+)$ of $(A,+)$ such that $\forall a \in A,\ \forall x \in I,\ ax \in I$. For $a \in A$, the principal ideal generated by $a$ is $(a) = aA = \{ax \mid x \in A\}$.

Définition. Un idéal d'un anneau commutatif $A$ est un sous-groupe $(I,+)$ de $(A,+)$ tel que $\forall a \in A,\ \forall x \in I,\ ax \in I$. Pour $a \in A$, l'idéal principal engendré par $a$ est $(a) = aA = \{ax \mid x \in A\}$.

Proposition. The ideals of $\mathbb{Z}$ are exactly the sets $n\mathbb{Z}$ for $n \in \mathbb{N}$.

Proposition. Les idéaux de $\mathbb{Z}$ sont exactement les $n\mathbb{Z}$ pour $n \in \mathbb{N}$.

Proof.

$n\mathbb{Z}$ is indeed an ideal of $\mathbb{Z}$. Conversely, let $I$ be an ideal of $\mathbb{Z}$. If $I = \{0\}$, it is $0\mathbb{Z}$. Otherwise, $I$ contains a nonzero integer, and since $I$ is closed under negation, it contains a strictly positive integer. Let $n$ be the smallest strictly positive element of $I$.

For any $a \in I$, Euclidean division gives $a = nq + r$ with $0 \le r < n$. We have $r = a - nq \in I$ (since $I$ is an ideal). By minimality of $n$, $r = 0$, so $a \in n\mathbb{Z}$. Thus $I \subset n\mathbb{Z}$, and the reverse inclusion is immediate, giving $I = n\mathbb{Z}$.

Démonstration.

$n\mathbb{Z}$ est bien un idéal de $\mathbb{Z}$. Réciproquement, soit $I$ un idéal de $\mathbb{Z}$. Si $I = \{0\}$, c'est $0\mathbb{Z}$. Sinon, $I$ contient un entier non nul, et comme $I$ est stable par opposé, $I$ contient un entier strictement positif. Soit $n$ le plus petit élément strictement positif de $I$.

Pour tout $a \in I$, la division euclidienne donne $a = nq + r$ avec $0 \le r < n$. On a $r = a - nq \in I$ (car $I$ est un idéal). Par minimalité de $n$, $r = 0$, donc $a \in n\mathbb{Z}$. Ainsi $I \subset n\mathbb{Z}$, et l'inclusion réciproque est immédiate, d'où $I = n\mathbb{Z}$.

Definition. The quotient ring $\mathbb{Z}/n\mathbb{Z}$ is the set of equivalence classes $\bar{a} = a + n\mathbb{Z}$ equipped with operations $\bar{a} + \bar{b} = \overline{a+b}$ and $\bar{a} \cdot \bar{b} = \overline{ab}$.

Définition. L'anneau quotient $\mathbb{Z}/n\mathbb{Z}$ est l'ensemble des classes $\bar{a} = a + n\mathbb{Z}$ muni des opérations $\bar{a} + \bar{b} = \overline{a+b}$ et $\bar{a} \cdot \bar{b} = \overline{ab}$.

Remark. The operations on $\mathbb{Z}/n\mathbb{Z}$ are well-defined: if $\bar{a} = \bar{a'}$ and $\bar{b} = \bar{b'}$, i.e. $n \mid (a'-a)$ and $n \mid (b'-b)$, then $n \mid (a'+b')-(a+b)$, so $\overline{a'+b'} = \overline{a+b}$. Moreover, $a'b' - ab = a'(b'-b) + (a'-a)b$, and $n$ divides both terms, so $\overline{a'b'} = \overline{ab}$.

Remarque. Les opérations sur $\mathbb{Z}/n\mathbb{Z}$ sont bien définies : si $\bar{a} = \bar{a'}$ et $\bar{b} = \bar{b'}$, i.e. $n \mid (a'-a)$ et $n \mid (b'-b)$, alors $n \mid (a'+b')-(a+b)$, donc $\overline{a'+b'} = \overline{a+b}$. De plus, $a'b' - ab = a'(b'-b) + (a'-a)b$, et $n$ divise les deux termes, donc $\overline{a'b'} = \overline{ab}$.

Theorem. $\mathbb{Z}/n\mathbb{Z}$ is a field if and only if $n$ is prime.

Théorème. $\mathbb{Z}/n\mathbb{Z}$ est un corps si et seulement si $n$ est premier.

Proof.

$(\Rightarrow)$ If $n$ is not prime and $n \ge 2$, write $n = ab$ with $1 < a,b < n$. Then $\bar{a} \neq \bar{0}$, $\bar{b} \neq \bar{0}$, but $\bar{a}\bar{b} = \bar{n} = \bar{0}$: there are zero divisors, so $\mathbb{Z}/n\mathbb{Z}$ is not a field.

$(\Leftarrow)$ Let $p$ be prime and $\bar{a} \neq \bar{0}$, i.e. $p \nmid a$. Then $\gcd(a,p)=1$, and by Bézout there exist $u,v \in \mathbb{Z}$ with $au+pv=1$. Reducing mod $p$: $\bar{a}\bar{u} = \bar{1}$, so $\bar{a}$ is invertible.

Démonstration.

$(\Rightarrow)$ Si $n$ n'est pas premier et $n \ge 2$, on écrit $n = ab$ avec $1 < a,b < n$. Alors $\bar{a} \neq \bar{0}$, $\bar{b} \neq \bar{0}$, mais $\bar{a}\bar{b} = \bar{n} = \bar{0}$ : il y a des diviseurs de zéro, donc $\mathbb{Z}/n\mathbb{Z}$ n'est pas un corps.

$(\Leftarrow)$ Soit $p$ premier et $\bar{a} \neq \bar{0}$, i.e. $p \nmid a$. Alors $\gcd(a,p)=1$, et par Bézout il existe $u,v \in \mathbb{Z}$ tels que $au+pv=1$. En passant modulo $p$ : $\bar{a}\bar{u} = \bar{1}$, donc $\bar{a}$ est inversible.

Proposition. The invertible elements of $\mathbb{Z}/n\mathbb{Z}$ are the classes $\bar{a}$ with $\gcd(a,n) = 1$: $(\mathbb{Z}/n\mathbb{Z})^\times = \{\bar{a} \mid \gcd(a,n) = 1\}$.

Proposition. Les inversibles de $\mathbb{Z}/n\mathbb{Z}$ sont les classes $\bar{a}$ avec $\gcd(a,n) = 1$ : $(\mathbb{Z}/n\mathbb{Z})^\times = \{\bar{a} \mid \gcd(a,n) = 1\}$.

Proof.

$(\Rightarrow)$ If $\bar{a}$ is invertible, there exists $\bar{u}$ with $\bar{a}\bar{u} = \bar{1}$, i.e. $au \equiv 1 \pmod{n}$. So there exists $v$ with $au + nv = 1$, which forces $\gcd(a,n) = 1$.

$(\Leftarrow)$ If $\gcd(a,n) = 1$, by Bézout there exist $u,v$ with $au + nv = 1$, giving $\bar{a}\bar{u} = \bar{1}$.

Démonstration.

$(\Rightarrow)$ Si $\bar{a}$ est inversible, il existe $\bar{u}$ tel que $\bar{a}\bar{u} = \bar{1}$, i.e. $au \equiv 1 \pmod{n}$. Donc il existe $v$ tel que $au + nv = 1$, ce qui impose $\gcd(a,n) = 1$.

$(\Leftarrow)$ Si $\gcd(a,n) = 1$, par Bézout il existe $u,v$ tels que $au + nv = 1$, d'où $\bar{a}\bar{u} = \bar{1}$.

Definition. Euler's totient function $\varphi(n) = |(\mathbb{Z}/n\mathbb{Z})^\times|$ is the number of integers in $\{1,\dots,n\}$ coprime to $n$.

Définition. L'indicatrice d'Euler $\varphi(n) = |(\mathbb{Z}/n\mathbb{Z})^\times|$ est le nombre d'entiers de $\{1,\dots,n\}$ premiers à $n$.

Theorem (Euler). If $\gcd(a,n) = 1$, then $a^{\varphi(n)} \equiv 1 \pmod{n}$.

Théorème (Euler). Si $\gcd(a,n) = 1$, alors $a^{\varphi(n)} \equiv 1 \pmod{n}$.

Proof.

$\bar{a} \in (\mathbb{Z}/n\mathbb{Z})^\times$, which is a group of order $\varphi(n)$. By Lagrange's theorem, the order of $\bar{a}$ divides $\varphi(n)$, so $\bar{a}^{\varphi(n)} = \bar{1}$.

Démonstration.

$\bar{a} \in (\mathbb{Z}/n\mathbb{Z})^\times$, qui est un groupe d'ordre $\varphi(n)$. Par le théorème de Lagrange, l'ordre de $\bar{a}$ divise $\varphi(n)$, donc $\bar{a}^{\varphi(n)} = \bar{1}$.

Corollary (Fermat's little theorem). If $p$ is prime and $p \nmid a$, then $a^{p-1} \equiv 1 \pmod{p}$ (since $\varphi(p) = p-1$).

Corollaire (Petit théorème de Fermat). Si $p$ est premier et $p \nmid a$, alors $a^{p-1} \equiv 1 \pmod{p}$ (car $\varphi(p) = p-1$).

Definition. The characteristic of a ring $A$, denoted $\mathrm{char}(A)$, is the smallest integer $n \ge 1$ such that $n \cdot 1_A = 0_A$, or $0$ if no such integer exists.

Définition. La caractéristique d'un anneau $A$, notée $\mathrm{car}(A)$, est le plus petit entier $n \ge 1$ tel que $n \cdot 1_A = 0_A$, ou $0$ si un tel entier n'existe pas.

Proposition. The characteristic of an integral domain (in particular of a field) is $0$ or a prime number.

Proposition. La caractéristique d'un anneau intègre (donc en particulier d'un corps) est $0$ ou un nombre premier.

Proof.

Suppose $\mathrm{char}(A) = n \ge 2$ and $n = ab$ with $1 \le a, b < n$. Then $0 = n \cdot 1_A = (a \cdot 1_A)(b \cdot 1_A)$. By the integral domain property, $a \cdot 1_A = 0$ or $b \cdot 1_A = 0$, contradicting the minimality of $n$. So $n$ is prime.

Démonstration.

Supposons $\mathrm{car}(A) = n \ge 2$ et $n = ab$ avec $1 \le a, b < n$. On a $0 = n \cdot 1_A = (a \cdot 1_A)(b \cdot 1_A)$. Par intégrité, $a \cdot 1_A = 0$ ou $b \cdot 1_A = 0$, ce qui contredit la minimalité de $n$. Donc $n$ est premier.

Theorem (Binomial formula in characteristic $p$). Let $A$ be a commutative ring of characteristic $p$ (prime). For all $a,b \in A$: $(a+b)^p = a^p + b^p$. More generally, $(a+b)^{p^n} = a^{p^n} + b^{p^n}$ for all $n \ge 1$.

Théorème (Formule du binôme en caractéristique $p$). Soit $A$ un anneau commutatif de caractéristique $p$ (premier). Pour tous $a,b \in A$ : $(a+b)^p = a^p + b^p$. Plus généralement, $(a+b)^{p^n} = a^{p^n} + b^{p^n}$ pour tout $n \ge 1$.

Proof.

By the binomial theorem, $(a+b)^p = \sum_{k=0}^{p} \binom{p}{k} a^k b^{p-k}$. For $1 \le k \le p-1$, $p \mid \binom{p}{k}$ since $p \mid p!$ and $p \nmid k!$, $p \nmid (p-k)!$, so $(a+b)^p = a^p + b^p$. By induction: $(a+b)^{p^n} = ((a+b)^{p^{n-1}})^p = (a^{p^{n-1}} + b^{p^{n-1}})^p = a^{p^n} + b^{p^n}$.

Démonstration.

Par la formule du binôme de Newton, $(a+b)^p = \sum_{k=0}^{p} \binom{p}{k} a^k b^{p-k}$. Pour $1 \le k \le p-1$, $p \mid \binom{p}{k}$ car $p \mid p!$ et $p \nmid k!$, $p \nmid (p-k)!$, donc $(a+b)^p = a^p + b^p$. Par récurrence : $(a+b)^{p^n} = ((a+b)^{p^{n-1}})^p = (a^{p^{n-1}} + b^{p^{n-1}})^p = a^{p^n} + b^{p^n}$.

Corollary. The map $F : a \mapsto a^p$ is a ring homomorphism from $A$ to $A$ (called the Frobenius endomorphism).

Corollaire. L'application $F : a \mapsto a^p$ est un morphisme d'anneaux de $A$ dans $A$ (appelé morphisme de Frobenius).

Proof.

$F(ab) = (ab)^p = a^p b^p = F(a)F(b)$ by commutativity, $F(a+b) = a^p + b^p = F(a) + F(b)$, and $F(1) = 1$.

Démonstration.

$F(ab) = (ab)^p = a^p b^p = F(a)F(b)$ par commutativité, $F(a+b) = a^p + b^p = F(a) + F(b)$, et $F(1) = 1$.

Exercises

Exercices

Exercise. Let $A$ be a finite ring. Show that every element of $A$ is either invertible or a zero divisor.

Exercice. Soit $A$ un anneau fini. Montrer que tout élément de $A$ est soit inversible, soit diviseur de zéro.

Proof.

Let $a \in A$ and $\varphi : A \to A$ defined by $\varphi(x) = ax$. If $\varphi$ is injective, since $A$ is finite, $\varphi$ is surjective: there exists $b \in A$ with $ab = 1$, so $a$ is invertible. Otherwise, there exist $x \neq y$ with $ax = ay$, giving $a(x-y) = 0$ with $x - y \neq 0$: $a$ is a zero divisor.

Démonstration.

Soit $a \in A$ et $\varphi : A \to A$ définie par $\varphi(x) = ax$. Si $\varphi$ est injective, comme $A$ est fini, $\varphi$ est surjective : il existe $b \in A$ tel que $ab = 1$, donc $a$ est inversible. Sinon, il existe $x \neq y$ tels que $ax = ay$, d'où $a(x-y) = 0$ avec $x - y \neq 0$ : $a$ est diviseur de zéro.

Exercise. Show that $\mathbb{Z}[i] = \{a+ib \mid a,b \in \mathbb{Z}\}$ is a subring of $\mathbb{C}$, and determine its invertible elements.

Exercice. Montrer que $\mathbb{Z}[i] = \{a+ib \mid a,b \in \mathbb{Z}\}$ est un sous-anneau de $\mathbb{C}$, et déterminer ses inversibles.

Proof.

$1 = 1 + 0i \in \mathbb{Z}[i]$. If $z = a+ib$ and $z' = a'+ib'$ are in $\mathbb{Z}[i]$, then $z - z' = (a-a') + i(b-b') \in \mathbb{Z}[i]$ and $zz' = (aa'-bb') + i(ab'+a'b) \in \mathbb{Z}[i]$. By the subring criterion, $\mathbb{Z}[i]$ is a subring of $\mathbb{C}$.

Let $z = a+ib \in \mathbb{Z}[i]$ be invertible in $\mathbb{Z}[i]$. Then there exists $z' \in \mathbb{Z}[i]$ with $zz' = 1$, so $|z|^2 |z'|^2 = 1$. Since $|z|^2 = a^2 + b^2 \in \mathbb{N}$ and $|z'|^2 \in \mathbb{N}$, we have $a^2 + b^2 = 1$, so $(a,b) \in \{(\pm 1, 0), (0, \pm 1)\}$. Thus $\mathbb{Z}[i]^\times = \{1, -1, i, -i\}$.

Démonstration.

$1 = 1 + 0i \in \mathbb{Z}[i]$. Si $z = a+ib$ et $z' = a'+ib'$ sont dans $\mathbb{Z}[i]$, alors $z - z' = (a-a') + i(b-b') \in \mathbb{Z}[i]$ et $zz' = (aa'-bb') + i(ab'+a'b) \in \mathbb{Z}[i]$. Par le critère de sous-anneau, $\mathbb{Z}[i]$ est un sous-anneau de $\mathbb{C}$.

Soit $z = a+ib \in \mathbb{Z}[i]$ inversible dans $\mathbb{Z}[i]$. Alors il existe $z' \in \mathbb{Z}[i]$ tel que $zz' = 1$, d'où $|z|^2 |z'|^2 = 1$. Comme $|z|^2 = a^2 + b^2 \in \mathbb{N}$ et $|z'|^2 \in \mathbb{N}$, on a $a^2 + b^2 = 1$, donc $(a,b) \in \{(\pm 1, 0), (0, \pm 1)\}$. Ainsi $\mathbb{Z}[i]^\times = \{1, -1, i, -i\}$.

Exercise (Nilradical). Let $A$ be a commutative ring. Show that the set of nilpotent elements $\mathcal{N} = \{a \in A \mid \exists n \ge 1,\ a^n = 0\}$ is an ideal of $A$.

Exercice (Nilradical). Soit $A$ un anneau commutatif. Montrer que l'ensemble des nilpotents $\mathcal{N} = \{a \in A \mid \exists n \ge 1,\ a^n = 0\}$ est un idéal de $A$.

Proof.

$0 \in \mathcal{N}$. If $a^p = 0$ and $b^q = 0$, set $n = p+q-1$. In the binomial expansion $(a-b)^n = \sum_{k=0}^{n} \binom{n}{k} a^k (-b)^{n-k}$, each term vanishes: if $k \ge p$ then $a^k = 0$, otherwise $n-k \ge q$ so $b^{n-k} = 0$. Thus $a - b \in \mathcal{N}$. Finally, if $a^n = 0$ and $r \in A$, then $(ra)^n = r^n a^n = 0$, so $ra \in \mathcal{N}$.

Démonstration.

$0 \in \mathcal{N}$. Si $a^p = 0$ et $b^q = 0$, posons $n = p+q-1$. Dans le binôme $(a-b)^n = \sum_{k=0}^{n} \binom{n}{k} a^k (-b)^{n-k}$, chaque terme est nul : si $k \ge p$ alors $a^k = 0$, sinon $n-k \ge q$ donc $b^{n-k} = 0$. Ainsi $a - b \in \mathcal{N}$. Enfin, si $a^n = 0$ et $r \in A$, alors $(ra)^n = r^n a^n = 0$, donc $ra \in \mathcal{N}$.

Exercise. Show that in $\mathbb{Z}/n\mathbb{Z}$, an element is nilpotent if and only if every prime factor of $n$ divides that element.

Exercice. Montrer que dans $\mathbb{Z}/n\mathbb{Z}$, un élément est nilpotent si et seulement si tous les facteurs premiers de $n$ divisent cet élément.

Proof.

Let $n = p_1^{\alpha_1} \cdots p_r^{\alpha_r}$. $(\Rightarrow)$ If $\bar{a}^k = \bar{0}$, then $n \mid a^k$, so $p_i \mid a^k$ for all $i$, and since $p_i$ is prime, $p_i \mid a$. $(\Leftarrow)$ If all $p_i$ divide $a$, write $a = p_1 \cdots p_r \cdot q$. Set $M = \max(\alpha_i)$. Then $a^M = p_1^M \cdots p_r^M \cdot q^M$, and since $M \ge \alpha_i$, we have $n = p_1^{\alpha_1} \cdots p_r^{\alpha_r} \mid p_1^M \cdots p_r^M \mid a^M$, so $\bar{a}^M = \bar{0}$.

Démonstration.

Soit $n = p_1^{\alpha_1} \cdots p_r^{\alpha_r}$. $(\Rightarrow)$ Si $\bar{a}^k = \bar{0}$, alors $n \mid a^k$, donc $p_i \mid a^k$ pour tout $i$, et comme $p_i$ est premier, $p_i \mid a$. $(\Leftarrow)$ Si tous les $p_i$ divisent $a$, on écrit $a = p_1 \cdots p_r \cdot q$. Posons $M = \max(\alpha_i)$. Alors $a^M = p_1^M \cdots p_r^M \cdot q^M$, et comme $M \ge \alpha_i$, on a $n = p_1^{\alpha_1} \cdots p_r^{\alpha_r} \mid p_1^M \cdots p_r^M \mid a^M$, donc $\bar{a}^M = \bar{0}$.

Exercise. Prove Fermat's little theorem: if $p$ is prime, then for all $a \in \mathbb{Z}$, $a^p \equiv a \pmod{p}$.

Exercice. Montrer le petit théorème de Fermat : si $p$ est premier, alors pour tout $a \in \mathbb{Z}$, $a^p \equiv a \pmod{p}$.

Proof.

If $p \mid a$, both sides are $\equiv 0$. Otherwise, $\bar{a} \in (\mathbb{Z}/p\mathbb{Z})^\times$ which has order $p-1$, so $a^{p-1} \equiv 1 \pmod{p}$ by Lagrange, giving $a^p \equiv a$.

Démonstration.

Si $p \mid a$, les deux membres sont $\equiv 0$. Sinon, $\bar{a} \in (\mathbb{Z}/p\mathbb{Z})^\times$ qui est d'ordre $p-1$, donc $a^{p-1} \equiv 1 \pmod{p}$ par Lagrange, d'où $a^p \equiv a$.
